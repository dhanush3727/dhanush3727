# 💻 Featured Project

## 🔧 Maintix — Multi-Tenant Equipment Maintenance Management System

**Maintix** is a full-stack multi-tenant SaaS platform designed to help organizations manage equipment and maintenance operations through a centralized system.

### Key Features

- 🔐 Authentication & Authorization
- 👥 Role-Based Access Control (RBAC)
- 🏢 Multi-Tenant Architecture
- 🏭 Multi-Factory Management
- ⚙️ Equipment Management
- 📅 Preventive Maintenance
- 🔧 Breakdown Maintenance
- ✅ Maintenance Checklists
- 📊 Dashboard & Maintenance Analytics
- 📈 MTBF & MTTR Reports
- 🔔 Notifications
- 👤 User & Access Management
- 🔎 Search, Filtering & Pagination

### Technology

**React.js · Next.js · TypeScript · Tailwind CSS · Zustand · TanStack Query · NestJS · PostgreSQL · Prisma**

### Architecture & Engineering

- Designed a multi-tenant architecture with organization and factory-level data isolation.
- Implemented authentication and authorization using JWT-based access and refresh tokens.
- Implemented role-based access control with granular permissions.
- Built RESTful APIs using NestJS and Prisma ORM.
- Designed and managed relational data using PostgreSQL.
- Implemented server-state management and API caching using TanStack Query.
- Built reusable and responsive UI components using React.js, Next.js, and Tailwind CSS.
- Implemented pagination, filtering, search, and efficient API data fetching.
- Developed preventive maintenance, breakdown maintenance, checklist, scheduling, notification, dashboard, and reporting modules.
